# Aula 01 — Modelagem Relacional e Restrições de Integridade

## Conteúdos

Nesta aula foram trabalhados conceitos de modelagem relacional,
DDL e restrições de integridade no MySQL/MariaDB.

Principais conceitos

- PRIMARY KEY
- FOREIGN KEY
- UNIQUE
- CHECK
- NOT NULL
- AUTO_INCREMENT
- ALTER TABLE
- ON DELETE RESTRICT
- ON UPDATE CASCADE

 Atividades

Desafio 1 — Clientes e Empréstimos

Criação das tabelas `CLIENTES` e `EMPRESTIMOS`, utilizando:

- Chave primária
- Chave estrangeira
- UNIQUE
- CHECK
- NOT NULL
- AUTO_INCREMENT
- ON DELETE RESTRICT

Desafio 2 — Empresas e Funcionários

Aplicação de restrições utilizando `ALTER TABLE`:

- PRIMARY KEY
- FOREIGN KEY
- CHECK
- ON UPDATE CASCADE
- ON DELETE RESTRICT

As tabelas `Empresas` e `Funcionarios` já faziam parte
da estrutura fornecida para o exercício.

## Tecnologias

- MySQL / MariaDB
- SQL
